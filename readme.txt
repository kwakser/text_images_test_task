Avito Text Orientation Classification

Решение задачи определения ориентации текстовых crop'ов. Для каждого изображения модель предсказывает `p_180` — вероятность того, что текст находится вверх ногами.

Подход

Так как исходные labels не предоставлялись, для обучения использовалась синтетическая разметка. Для каждого изображения `x` создавалась пара:

```text
(x, rot180(x))       → 0
(rot180(x), x)       → 1
```

Train/validation split выполнялся **до генерации rotated-версий**, чтобы избежать leakage.

Использовалась Siamese-модель на базе pretrained ResNet-18. Обе версии изображения проходят через общий backbone, после чего их признаки сравниваются.

Preprocessing:

* RGB;
* resize с сохранением пропорций;
* padding до `224 × 64`;
* нормализация.

Результат

Лучший validation результат:

```text
Brier Score: 0.2633
Score:       0.7367
Accuracy:    0.5034
```

Итоговый `submission.csv` был сформирован с использованием checkpoint с лучшим validation Brier Score.

Анализ

Результат ограничен тем, что validation labels являются синтетическими: модель обучается на точных 180°-парах, тогда как реальные тестовые изображения могут содержать различные шрифты, языки, качество и визуальные особенности.

При дальнейшем обучении train loss продолжал снижаться, но validation Brier ухудшался:

```text
Epoch 1:  Score = 0.7367
Epoch 2:  Score = 0.6683
Epoch 3:  Score = 0.6273
```

При этом accuracy оставалась около `0.5`, а разброс predicted probabilities увеличивался. Это указывает на переобучение: модель становилась более уверенной, не получая соответствующего улучшения на новых изображениях.

Поэтому для submission использовался checkpoint первой эпохи с лучшим validation Brier.
